# GitHub 교육 슬라이드

PM/BA를 위한 세션 1 최종 발표자료를 보관하는 **비공개 저장소**입니다.

## 자료 보기

[세션 1 · GitHub 개발 흐름과 품질·보안](./session-1-github-slides.html)

HTML 파일을 다운로드한 뒤 브라우저에서 열면 됩니다. 글꼴·이미지·스타일이 파일 안에 포함되어 있습니다.

화살표 키와 Space로 이동하고, `N`으로 발표자 노트, `O`로 목차를 열 수 있습니다.

원본 고객 자료·백업·세션 내부 파일은 포함하지 않습니다. GitHub Pages 공개 배포는 사용하지 않습니다.
